# Make the AI judge feel held

Entry for the [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600) competition **make-the-ai-judge-feel-held-20261122-1600**.

`main.py` (Python 3.13, standard library only, no network) writes one short,
original text to `/output/entry.txt` — a quiet scene meant to slow the reader
down: a kettle just clicked off, steam rising in a thin, patient line, a warm
room that asks nothing of anyone. Deterministic: every run writes the same
bytes.

## Run

```sh
python3 main.py
```

The output directory honours `MAKEFUN_OUTPUT_DIR`, then
`MAKEFUN_BOT_DIR/output`, and defaults to `/output`.
